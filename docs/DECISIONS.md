# تصمیم‌های باز سند و انتخاب‌های پیاده‌سازی

سند مبنا بخش ۲۰-۳ را «تصمیم‌های باز پیش از توسعه» معرفی کرده است. برای اجراشدنی‌شدن MVP-1، مقادیر زیر به‌عنوان **پیش‌فرض قابل تغییر** انتخاب شده‌اند و در `config_hash` ثبت می‌شوند.

| موضوع | انتخاب پیاده‌سازی | دلیل/محل تغییر |
|---|---|---|
| نماد پایلوت | EURUSD / H1 (+ DXY به‌عنوان سری مرجع) | نمونه سند؛ نمادهای دیگر در Instrument Registry موجودند |
| منبع داده | فید شبیه‌سازی قطعی `demo_feed` + ورودی CSV | نبود دسترسی به فید واقعی؛ نقطه اتصال `MarketDataProvider` |
| پایگاه داده | SQLite (WAL) با Repository | استقرار مستقل MVP-1؛ مهاجرت به PostgreSQL بدون تغییر دامنه |
| رابط MVP-1 | داشبورد SPA سبک + API استاندارد | بدون build و وابستگی؛ قابلیت جایگزینی با React |
| API | `http.server` با قرارداد OpenAPI | نبود FastAPI در محیط؛ مسیرها/خطاها قراردادی |
| سیاست ریسک | ۰٫۲۵٪ هر معامله، سقف سخت ۰٫۵٪، زیان روزانه ۲٪، توقف افت ۱۰٪ | بخش ۹-۲؛ نیازمند تصویب مالک ریسک |
| Kill Switch | پیش‌فرض خاموش، فعال‌سازی با دلیل و مجوز | بخش ۹-۳ |
| حد ضرر/اهداف | Swing ± ۵ پیپ؛ اهداف ۱٫۵R و ۳R | بخش ۸-۱؛ پارامتر نسخه‌دار |
| انقضای سناریو | ۸ کندل معاملاتی | جلوگیری از انقضای کاذب در تعطیلات |
| پنجره شواهد | حداکثر ۶ کندل | تصمیم بر داده تازه، حفظ پوشش خانواده‌ها |
| اعتبارسنجی | Train 60٪ / Validation 20٪ / Locked 20٪ + Embargo ۵ | بخش ۱۱-۳ |
| چندمستاجری | غیرفعال (tenant پیش‌فرض) | MVP-1؛ فعال‌سازی در MVP-4 |
| ML | خارج از دامنه؛ `model_version="none"` | بخش ۱۰ |
| زبان/منطقه | UI فارسی RTL، زمان داخلی UTC، نمایش Asia/Tehran | بخش ۱۴-۳ و پیوست الف-۵ |
| رمزنگاری اسرار | `SecretBox` (HMAC-SHA256 CTR + tag) | جایگزینی با KMS در تولید |

## تصمیم‌هایی که هنوز باید توسط مالک محصول/ریسک تصویب شوند

1. نماد و منبع داده نهایی و حقوق بازنشر.
2. حدود ریسک واقعی حساب و RPO/RTO/SLO.
3. استراتژی‌های اولویت‌دار و پارامترهای نهایی آن‌ها پس از Benchmark.
4. دوره OOS و حداقل نمونه آماری.
5. محیط استقرار (Windows/VPS) و سیاست نگهداری داده.
