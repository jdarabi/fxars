# دامنه MVP تکمیلی و معیارهای خروج

این فایل دامنه «MVP تکمیلی ۱.۱» را تنگ‌تر و عددی می‌کند. هر معیار باید با آزمون یا شاهد اجرایی قابل اثبات باشد؛ معیار بدون شاهد، «باز» محسوب می‌شود.

## ۱. در دامنه (MVP)

| حوزه | تعهد |
|---|---|
| نماد و تایم‌فریم پایلوت | EURUSD روی H1 (M15 برای تنظیمات کوتاه‌مدت) |
| منبع داده | MT5 به‌عنوان منبع اصلی؛ `demo_feed` فقط برای آزمون |
| تحلیل | ساختار، تکنیکال، پرایس‌اکشن، نوسان، رژیم و ۸ خانواده شاهد |
| تصمیم | امتیاز ترکیبی، بودجه عدم‌قطعیت، NO TRADE اجباری |
| ریسک | اندازه موقعیت با هزینه، دروازه گسترده، قفل ریسک، Kill Switch سه‌سطحی |
| پژوهش | بک‌تست OOS، Walk-forward، PBO/DSR، دروازه پذیرش |
| اجرا | Paper/Demo و فازهای ASSISTED/AUTOMATED_LIMITED با سقف سخت |
| حاکمیت | Provenance، Policy Registry، Model Card/Tier، Audit زنجیره‌ای |
| محصول | داشبورد فارسی RTL با تب تحلیل/ریسک/عملیات/هوشمندی تصمیم |

## ۲. خارج از دامنه (در MVP تکمیلی)

- مدل Tier 3 و تصمیم کاملاً خودمختار بدون تأیید حاکمیت.
- اجرای چندکارگزار هم‌زمان و مسیریابی سفارش (Smart Order Routing).
- یادگیری آنلاین و بازآموزی خودکار مدل در تولید.
- پیش‌بینی قیمت به‌عنوان «احتمال» بدون کالیبراسیون.
- تضمین سود یا ادعای دقت خارج از نمونه.

## ۳. معیارهای خروج عددی

| معیار | حد عبور | شاهد |
|---|---|---|
| قابلیت بازتولید | اجرای دوباره با snapshot/config یکسان = همان `run_id`/`result_hash` | `test_ac02_analysis_reproducible` |
| اعتماد داده | هیچ تحلیلی با `DTS < 0.60` منتشر نشود | `tests/test_decision_policy.py` |
| عدم‌قطعیت | هیچ تصمیمی با `U > 0.60` صادر نشود | `tests/test_decision_policy.py` |
| منشأ تصمیم | ۱۰۰٪ تحلیل‌های ذخیره‌شده رکورد Provenance معتبر دارند | `tests/test_governance.py` |
| بک‌تست | حداقل ۲۰۰ معامله OOS، PF ≥ ۱٫۲، MDD ≤ ۱۵٪، شارپ > ۰ | `research-gate --strict` |
| هزینه | کل هزینه‌ها > ۰ و تفکیک‌شده | `test_ac07_backtest_costs_are_separated` |
| ریسک | هیچ سفارشی بدون RiskDecision تأییدشده و تازه | `tests/test_execution.py` |
| زیان روزانه/هفتگی | عبور از سقف ⇒ قفل و توقف سفارش | `tests/test_risk_lock.py` |
| سشن | سفارش خارج از بازار باز (با grace) رد شود | `tests/test_risk.py` |
| Kill Switch | فعال‌سازی هر سطح ⇒ توقف ارسال و Audit | `tests/test_risk_lock.py` |
| ممیزی | حذف/ویرایش رکورد ممیزی ممکن نباشد | `test_ac10_audit_append_only` |
| مستندات | نصب/پیکربندی/پشتیبان‌گیری/بازگردانی موجود | `test_ac12_operational_docs_exist` |
